# Artifacts

M1 adds `ArtifactId` as a provider-neutral reference so discovery results can identify future outputs without embedding content in core domain data. There is no artifact store, artifact metadata model, OpenAPI generator, or generated client yet.

M5 is responsible for the artifact foundation and OpenAPI 3.1 generation. Generated Rust, CLI, MCP, and TypeScript artifacts are intentionally deferred to their dedicated milestones.
